so what's a reverse proxy?

think of my server as an apartment building. every website lives in its own apartment (a docker container), but they all share one street address.

a reverse proxy is the front desk. when you arrive, it checks which name you asked for, locks the conversation with https, and walks you to the right door. mine is called traefik, and it's why one tiny server can host many sites.
